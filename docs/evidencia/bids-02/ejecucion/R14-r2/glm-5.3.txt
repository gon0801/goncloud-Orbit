+BEGIN

CREATE OR REPLACE FUNCTION impulso_grupo_es_impulso() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
    IF (SELECT tipo FROM campana_grupo WHERE id = NEW.grupo_id) IS DISTINCT FROM 'impulso' THEN
        RAISE EXCEPTION 'impulso %: el grupo % no es de tipo impulso', NEW.id, NEW.grupo_id;
    END IF;
    RETURN NEW;
END;
$$;

    BEFORE INSERT ON impulso
    FOR EACH ROW
    EXECUTE FUNCTION impulso_grupo_es_impulso();

BEGIN
    IF NEW.tipo IS DISTINCT FROM 'impulso'

    END IF;
    RETURN NEW;
END;
$$;

## Hallazgos

**1. BLOQUEANTE — `app/impulso_io.py:780-792` (en 3430b2d): la rama H10 sella un segundo impulso vivo del mismo producto.**
El candado por producto (R09-G) quedó *después* del bloque de huérfanos: la rama "huerfano applied del mismo lote" hace `_sella_impulso` (línea 780) y `continue` (782) **antes** de que corra `vivo = conn.execute(_SQL_VIVO_PRODUCTO, ...)` (792). Reproducción: lanzamiento con huella H1 en L1 que muere tras quedar applied (huérfano sin fila impulso) → luego se lanza otro listing L2 del mismo producto (sin vivo visible, pasa) → al reintentar L1/H1, la rama 780 reactiva y sella → dos vivos por producto. Lectura: `git show 3430b2d:app/impulso_io.py | sed -n '752,800p'`. Ya corregido fuera del rango por 74a1a0c (`_falla_si_hay_vivo` antes de reutilizar huérfanos).

**2. BLOQUEANTE — `migrations/0071_reversa_bids02_grant_vista_impulso.sql:7`: la reversa revoca más de lo que la 0071 dio.**
En producción `app_read`/`app_admin` ya tenían SELECT sobre la vista por el ACL materializado por `ALTER DEFAULT PRIVILEGES ... GRANT SELECT ON TABLES` (`migrations/0001_initial.sql:1521`); el GRANT de la 0071 es un no-op y el REVERSE de la reversa les **quita** ese acceso previo (post-reversa ≠ pre-0071). Ejecutar la reversa rompe la lectura de `v_impulso_estado` (`app/pantalla_productos.py:263`, "Impulsos en curso"). El test lo enmascara: `tests/test_migracion_0071.py:47` hace un REVOKE previo "sin depender de los default privileges", un estado que no es el de producción. La reversa debería limitarse a restaurar el ACL previo (o re-grantear SELECT al revertir).
