# Como se produjo checklist-antes-del-deploy.txt (2026-10-06, solo lectura)

Comando (desde la raiz del repo, rama jev02/s4-job):

    STAMP=$(date -u +%Y%m%d-%H%M)
    bash docs/evidencia/jev-ads-02/ejecucion/S.4/checklist.sh "$STAMP" --antes \
      > docs/evidencia/jev-ads-02/ejecucion/S.4/checklist-antes-del-deploy.txt
    echo "exit=$?"

Sello: 20261006-1843. Exit: 1 (3 FALLAs, cada una la cambia el despliegue;
ver justificacion abajo). Sin secretos: el archivo se guardo pasando por
sed (home del operador -> ~) y se verifico con grep que no trae passwords,
ORBIT_DSN_* ni URLs postgres.

El modo --antes NO ejecuta `python -m app.cli jev-senales` en prod (lo
corre desplegar.sh en su paso 7) y no toca el crontab: el seco se sustituye
por `test -f app/jev_senales.py` dentro del contenedor.

Justificacion de las 3 FALLAs (todo lo demas OK, 0 sin medir, ciclos
106/107 done posteriores al arranque):

1. `codigo jev-senales en el contenedor: ausente` -> lo cambia desplegar.sh
   pasos 3-6 (git archive del SHA aprobado + build + recrear app).
2. `bloque jev: ausente` (salud trae solo `plataformas`) -> lo cambia el
   mismo codigo nuevo (S.4 agrega la clave hermana `jev`).
3. `lineas jev-senales en el crontab: 0` -> la instala el dueno con el
   bloque del paso 8 de desplegar.sh, antes del checklist post.

crontab de gon sin linea jev-senales, linea de precio instalada suelta
