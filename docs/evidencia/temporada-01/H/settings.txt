## Qué cambió y qué no (diff de claves 57 -> 59)

```
with a as (select settings::jsonb s from config_version where id = 57),
     b as (select settings::jsonb s from config_version where id = 59)
select coalesce(ka.key, kb.key) as clave, ka.value as antes, kb.value as despues
  from jsonb_each_text((select s from a)) ka
  full join jsonb_each_text((select s from b)) kb using (key)
 where ka.value is distinct from kb.value
 order by 1
```
