## 1) Major: variación con cobertura distinta POR MÉTRICA

Antes: `variacion()` solo comparaba `dias_con_dato`. Dos periodos podían empatar
en días con dato y tener coberturas distintas por métrica: con gasto
`10, null` frente a `10, 10` publicaba `cost_pct = -50.00` comparando sumas
incompletas.

Ahora:
- `totales_dias()` expone `dias_cost`, `dias_ad_revenue` y `dias_clicks`.
- Cada variación (`cost_pct`, `ad_revenue_pct`, `clicks_pct`) se publica solo
  si la cobertura de ESA métrica es igual en ambos periodos y completa respecto
  de sus `dias_con_dato`.
- `acos_pp` y `roas_delta` exigen además `dinero_alineado` en ambos periodos y
  la misma cobertura de gasto/venta.
- `comparable`/`motivo` conservan su semántica global; el nuevo
  `motivo_por_metrica` declara por qué quedó `None` una variación por cobertura
  (`cobertura_distinta`, `cobertura_incompleta`, `cobertura_desconocida`,
  `dinero_no_alineado`). `None` = no fue problema de cobertura.

Prueba monetaria (nueva):

```
ORBIT_TEST_DSN="$DSN" uv run --frozen python -m pytest -q \
  tests/test_dashboard_resumen.py -k cobertura_por_metrica
-> 1 passed
```

Caso `10, null` vs `10, 10`: `cost_pct None`, `motivo_por_metrica.cost_pct =
"cobertura_distinta"`; `ad_revenue_pct "0.00"` y `clicks_pct "0.00"` sí se
publican; `acos_pp`/`roas_delta` `None` con `"dinero_no_alineado"`.

## 2) Minor: ejemplo imposible en `docs/DASHBOARD.md` §9.3

El ejemplo mostraba `"periodo": 30` con `"recortado": true`. En el código real
`recortado` solo puede ser `true` con rango personalizado (`periodo:
"personalizado"`); con periodo fijo siempre es `false`.

Corregido a `"periodo": "personalizado"` y se aclaró en el texto. Comprobado
contra la API real (reloj 05:15Z):

```
GET /api/dashboard/resumen?periodo=30
-> desde=2026-10-01 hasta=2026-10-30 dias=30 periodo=30
   hasta_solicitado=2026-10-30 recortado=False

GET /api/dashboard/resumen?desde=2026-10-01&hasta=2026-10-31
-> desde=2026-10-01 hasta=2026-10-30 dias=30 periodo=personalizado
   hasta_solicitado=2026-10-31 recortado=True
```
