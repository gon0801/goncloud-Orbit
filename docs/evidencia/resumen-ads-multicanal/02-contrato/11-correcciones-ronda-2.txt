## Bloqueante 1: D-1 en la zona local minima (no UTC)

Fuente de la zona:
- Amazon: el perfil v2 trae `timezone` (`app/ads/structure.py:7`); MX cierra en
  America/Mexico_City y US en America/Los_Angeles.
- MeLi: site MLM (`app/meli/ads_source.py`). El sync pide fechas con reloj UTC,
  pero el dia que publica la API es el local: el 21-ago visto a las 19:19 UTC
  traia 16% del gasto final (evidencia ADS-01).

Reproduccion directa (mismo instante del revisor):

```
.venv/bin/python - <<'EOF'
import datetime as dt, psycopg
from app import dashboard_resumen as r
instante = dt.datetime(2026, 11, 1, 5, 15, tzinfo=dt.UTC)
canales = ("amazon_mx", "amazon_us", "meli")
print(r.hoy_por_canal(canales, instante))
hoy = r.hoy_resumen(canales, instante)
v = r.ventana_resumen(periodo=7, desde=None, hasta=None, hoy=hoy)
print("hoy", hoy, "ventana", v.desde, v.hasta)
with psycopg.connect("postgresql://orbit@127.0.0.1:5434/postgres") as c:
    out = r.resumen(c, ventana=v, canales=canales, hoy=hoy, instante=instante)
for n, b in out["canales"].items():
    print(n, b["series"][-1]["fecha"], b["series"][-1]["cost"], b["totals"]["dias_con_dato"], "/", b["dias"])
EOF
```

Salida real:

```

amazon_us 2026-10-30 37.3700 7 / 7
meli 2026-10-30 300.5700 7 / 7
```

## Nota 2: totales por moneda sin metricas inventadas

Mismo JSON de `periodo=7` (instante fijo). Salida real:

```
amazon_mx cost 5765.0900 orders 29
meli cost 2705.8900 orders None
MXN cost 8470.9800 suma canales 8470.9800
MXN orders None cobertura {'cost': True, 'ad_revenue': True, 'clicks': True,
                           'orders': False, 'dias': True} completo False
```

`orders` de MeLi siempre NULL: el grupo MXN publica `orders: null` y lo
declara en `cobertura.orders`; no suma solo las ordenes de Amazon MX.
`completo` tambien exige `cobertura.dias` de todos los canales.
